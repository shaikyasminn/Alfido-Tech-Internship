# Alfido Tech Internship

This repository contains the projects completed during my Alfido Tech Data Science Internship.

## Task 1: Zomato Restaurant Data Analysis

Performed exploratory data analysis (EDA) on the Zomato dataset to identify insights related to restaurant ratings, cuisines, pricing, locations, and online ordering trends.

## Task 2: Loan Approval Prediction

Built a machine learning model to predict loan approval status using applicant details such as income, education, employment status, and credit history.

## Task 3: Instagram Data Analysis

Analyzed Instagram data to uncover engagement trends, content performance patterns, and audience behavior using data visualization and analytical techniques.

### Technologies Used

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, WordCloud, Google Colab
