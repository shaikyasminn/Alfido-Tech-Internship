# Zomato Restaurant Data Analysis

## Overview

This project focuses on exploratory data analysis (EDA) of the Zomato restaurant dataset to identify insights related to restaurant ratings, cuisines, pricing, locations, and customer preferences.

---

## Objective

The goal of this analysis is to:

* Perform data cleaning and preprocessing
* Analyze restaurant ratings and pricing trends
* Explore cuisine popularity and location hotspots
* Visualize important patterns using graphs and charts
* Provide business recommendations for restaurant platforms

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* WordCloud
* Google Colab / Jupyter Notebook

## Dataset

Source: Zomato Restaurant Dataset (Kaggle)

Dataset contains information about:

* Restaurant names
* Locations
* Cuisines
* Ratings
* Cost for two people
* Online ordering
* Table booking
* Restaurant types

---

## Key Analysis Performed

* Data Cleaning
* Missing Value Handling

* Exploratory Data Analysis (EDA)
* Correlation Analysis
* Business Insights & Recommendations

---

## Key Findings

* Most restaurants maintain ratings between 3.5 and 4.5.
* Online ordering restaurants tend to receive better ratings.
* Premium cuisines generally have higher customer satisfaction.
* Certain locations dominate restaurant density and engagement.
* Mid-priced restaurants provide the best value for customers.

## Recommendations

1. Partner with highly rated restaurants.
2. Promote online-order-enabled restaurants.
